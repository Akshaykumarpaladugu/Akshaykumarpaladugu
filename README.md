## ◈ The kind of things I build

I enjoy turning ideas into practical technology: Python applications, machine-learning experiments, data workflows, language-AI prototypes, and systems that connect software with the physical world.

- **AI & Machine Learning** — predictive modelling, model evaluation, feature preparation, and experimentation.
- **Generative AI** — exploring LLM-powered workflows, prompt engineering, embeddings, retrieval-augmented generation (RAG), and tool calling.
- **Data & Insights** — data cleaning, exploratory analysis, visualization, and translating datasets into useful findings.
- **Robotics & IoT** — sensor integration, microcontrollers, voice-enabled interactions, and real-time monitoring.
- **Application Development** — Python-based prototypes, Flask apps, and practical user interfaces.

> My focus: build useful, understandable solutions—not technology for technology's sake.
